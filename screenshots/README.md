## 📸 How to Capture Screenshots

### Method 1: Browser DevTools
1. Open the application
2. Press `F12` to open DevTools
3. Press `Ctrl+Shift+P` (Cmd+Shift+P on Mac)
4. Type "screenshot" and select "Capture full size screenshot"
5. Save as PNG with appropriate name

### Method 2: Snipping Tool (Windows)
1. Open Snipping Tool
2. Select "Rectangular Snip"
3. Capture the application window
4. Save as PNG with appropriate name

### Method 3: Browser Extensions
- Use "GoFullPage" or "FireShot" extensions
- Capture full page screenshots
- Save as PNG files

## 🎨 Screenshot Guidelines

### ✅ Do's:
- Use high resolution (1920x1080+)
- Show complete UI elements
- Use light theme for better visibility
- Include hover states where relevant
- Ensure text is readable

### ❌ Don'ts:
- Don't include browser UI elements (tabs, address bar)
- Don't use blurry or low-quality images
- Don't include personal data or sensitive information
- Don't crop important UI elements
